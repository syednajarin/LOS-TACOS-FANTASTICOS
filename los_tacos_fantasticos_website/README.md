# Los Tacos Fantasticos Website

Open `index.html` in a browser to preview the responsive website.

## Easy editing
- Menu prices are shown as `—` so no prices are invented.
- Business hours are intentionally not shown because they were not provided.
- Update menu items, reviews, phone, address, and images directly in `index.html`.
- Replace placeholder social links and connect the contact form to your preferred backend/email service.
- The site currently uses remote Unsplash images for food photography.

## Files
- index.html — complete page/content
- style.css — responsive design and animations
- script.js — mobile navigation, reveal animations, demo contact form
